# 墨页 · Windows 桌面版

推荐将单文件 **墨页安装包.exe** 发给别人，双击后点击“安装”即可。程序安装到当前用户，桌面和开始菜单会出现“墨页”，无需管理员权限。如果电脑缺少 WebView2，安装程序会联网下载并安装 Microsoft 官方组件。已具备组件的电脑可以离线安装。

文件夹版仍可双击 **安装墨页.cmd** 安装，也可以直接运行 **Moye.exe**，请保留同目录的组件和 app 文件夹。可以在 Windows 设置 → 应用 → 墨页中卸载；卸载会保留你的 Markdown 文件和恢复草稿。

## 打开与保存

- **打开文件 / Ctrl+O**：选择电脑上的一个或多个 Markdown 文件。
- **保存 / Ctrl+S**：保存回当前文件；新文档第一次保存时选择文件夹与文件名。
- **另存为 / Ctrl+Shift+S**：创建新的 `.md` 文件，并切换到新文件路径。
- 顶部显示实际文件路径，点击可在资源管理器中定位。标签上的圆点表示有修改尚未保存。
- 关闭文档或程序时，如有未保存内容，会提示保存、放弃或取消。
- 草稿恢复不会自动覆盖磁盘文件，仍需点击“保存”。

## 设为 Markdown 默认打开程序

安装后，在文件夹或桌面的空白处右键 → **新建 → Markdown 文档**，即可创建空白 `.md` 文件。此选项也可通过 **启用右键新建MD.cmd** 单独添加到已安装的墨页。

在 Windows 默认应用设置中找到“墨页”，将 `.md`（以及需要时的 `.markdown`）设为墨页。也可以使用墨页中的默认应用设置入口。

也可右键任意 `.md` 文件 → 打开方式 → 选择其他应用 → 墨页 → **始终**。

以后双击 Markdown 文件就会进入墨页；已有窗口会新增或切换到对应标签。

Windows 的默认应用选择需要你在系统窗口中完成。安装程序只注册“墨页”为候选，不修改受保护的 UserChoice 设置。

## 其他功能

保留多文档、绿色主题、可视化编辑、快捷键自定义、链接卡片、网页/视频展示及代码高亮。外部链接使用系统浏览器打开。获取网页标题需要联网，网站限制可能导致获取失败。

新建或另存为的文件使用 UTF-8；覆盖原文件时保留原有 UTF-8/UTF-16/GB18030 编码与常见换行方式。检测到磁盘文件被其他程序修改时，会提示你选择覆盖或另存为。

运行环境：64 位 Windows 10/11，.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。当前电脑已具备这些组件。本版本为本地构建，尚未进行代码签名。

程序安装位置：`%LOCALAPPDATA%\Programs\Moye`。编辑器的恢复草稿与设置位于 `%LOCALAPPDATA%\Moye\WebView2`，你的 Markdown 文件仍保存在自己选择的位置。
